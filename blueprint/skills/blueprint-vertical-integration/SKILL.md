# 纵向业务闭环验证；在对应验证或交付场景下使用。

为目标用户操作记录输入、网络请求、后端状态变化和最终界面投影。验证刷新、重连、重复操作和失败恢复后仍一致。
使用一个实际最小流程穿透集成边界，再覆盖影响最大的异常路径；不要只分别测试两端然后假定契约兼容。

执行前调用平台提供的 ensure_role_environment，核对本节点真实执行环境。缺项先准备并复核；安装失败或能力不兼容应返回具体证据，不把注册视为已加载。遵守平台工作区、权限和交付协议。
